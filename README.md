# liteHaze: Ultra-Lightweight and Energy-Efficient Haze Removal for Edge-Based Roadside Surveillance
MATLAB implementation of paper "liteHaze: Ultra-Lightweight and Energy-Efficient Haze Removal for Edge-Based Roadside Surveillance" (submitted to IEEE Internet of Things Journal)

## Getting Started
### Requirements
MATLAB with Image Processing Toolbox
### Running the Demo
1. Clone this repository
2. Open the repository in MATLAB
3. Run `demo('images/image_name.extension')` to test with provided sample images
4. The dehazed image will be saved in the current directory as `image_name_dehazed.extension`
